# uzbek-tg — telefonda sinash ro'yxati (2-faza)

> Tuzildi: 2026-10-25. Manba: `docs/REJA.md` → «Telegram bilan tenglik ro'yxati»dagi
> ⏳ bandlar. Hammasi **kod yozilgan, telefonda sinalmagan**.
> APK: `https://github.com/Abdulmajidkhan007/uzbek-tg/releases/latest/download/uzbek-tg.apk`

**Qanday to'ldiriladi:** har band yoniga ✅ (ishladi) yoki ❌ + nima bo'lgani
(qisqa: qaysi ekran, nima bosildi, nima chiqdi; skrinshot bo'lsa yaxshi).
Sinov uchun ikkinchi akkaunt yoki do'st bilan chat kerak (o'qildi/javob/yozmoqda
ikkinchi tomonda ko'rinadi). Rasmiy Telegram'da natijani solishtiring.

## 1. Xabarlar
- [ ] Formatlangan matn (qalin/kursiv/kod), havola bosiladi, kanalda inline tugma bosiladi
- [ ] Kanal postida ko'rishlar soni; xizmat xabarlari («X guruhga qo'shildi»)
- [ ] Javob (reply): xabarni surish/menyu → javob yozish → ikkinchi tomonda iqtibos bilan
- [ ] Tahrirlash: o'z xabarini tahrirlash → ikkinchi tomonda «tahrirlangan»
- [ ] Qoralama: chatda yozib chiqib ketish → ro'yxatda «Qoralama» → qaytsa matn turibdi
- [ ] «Yozmoqda...»: yozayotganda ikkinchi tomonda ko'rinadi

## 2. Media yuborish va saqlash
- [ ] Galereyadan rasm, video yuborish (biriktirish oynasi)
- [ ] Fayl yuborish (PDF yoki boshqa)
- [ ] Ovozli xabar yozish va yuborish (Android 10+ da OGG; eski telefonda ham sinab ko'ring)
- [ ] Joylashuv yuborish
- [ ] Rasm/videoni galereyaga saqlash; ulashish; faylni boshqa ilovada ochish

## 3. Maxfiylik va xavfsizlik
- [ ] Maxfiylik qoidalari (raqam, oxirgi faollik, rasm…) — o'zgartirib, ikkinchi akkauntdan tekshirish
- [ ] 2FA parol qo'yish/o'zgartirish (ehtiyot: parolni yozib qo'ying)
- [ ] Avto-o'chirish (xabar taymeri), akkaunt TTL qiymati saqlanadi
- [ ] Ma'lum cheklov: istisno ro'yxatini tahrirlash yo'q — sinash shart emas

## 4. Bildirishnomalar
- [ ] Sozlamalar: shaxsiy / guruh / kanal doiralari o'zgaradi va saqlanadi
- [ ] Ilova ochiq (fon'da) turganda yangi xabarga bildirishnoma keladi
- [ ] Ma'lum cheklov: ilova to'liq yopilganda push kelmaydi (Firebase kerak)

## 5. Akkaunt va qurilmalar
- [ ] Ism, bio, username, tug'ilgan kun o'zgaradi va rasmiy Telegram'da ko'rinadi
- [ ] Qurilmalar: seanslar ro'yxati, bitta seansni tugatish, avto-tugatish muddati
- [ ] Ma'lum cheklov: raqam almashtirish va QR kirish yo'q

## 6. Xotira va tarmoq
- [ ] Xotira: diagramma, toifa bo'yicha tozalash, saqlash muddati, chegara
- [ ] Trafik statistikasi ko'rinadi; avto-yuklash sozlamalari saqlanadi
- [ ] Proxy qo'shish va ulanish (bo'lsa)

## 7. Papkalar, ko'rinish, til
- [ ] Papka yaratish, tahrirlash, o'chirish → rasmiy Telegram'da ham o'zgaradi
- [ ] Chat sozlamalari: shrift o'lchami, burchak, fon, rang, kun/tun almashishi
- [ ] Til: uz / en / ru almashadi, ilova qayta ochilganda saqlanadi

## 8. 2026-10-15 qo'shilganlar

- [ ] Bir nechta xabarni tanlab o'chirish/uzatish
